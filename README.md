# HPC Training

A guided introduction to Georgia Tech's PACE Instructional Cluster Environment (ICE) for HAAG researchers. Start with access, run a first Slurm job, then learn how to manage storage and get help.

[Open the training website](https://human-augment-analytics.github.io/HPC-Training/) or use the modules below directly in this repository.

## Learning path

| Module | What you'll learn |
|---|---|
| [100 - Access and Setup](procedures/100%20-%20Access%20and%20Setup/README.md) | Connect through VPN, log into ICE, understand PACE, and find orientation resources. |
| [200 - Running Your First Job](procedures/200%20-%20Running%20Your%20First%20Job/README.md) | Estimate resources, choose a CPU or GPU setup, submit a Slurm job, and check its output. |
| [300 - Storage, Troubleshooting & Support](procedures/300%20-%20Storage%2C%20Troubleshooting%20%26%20Support/README.md) | Manage storage, check scripts and system status, and get help. |

Already have ICE access? Start with [Module 200](procedures/200%20-%20Running%20Your%20First%20Job/README.md). For a full list of lessons, see the [curriculum overview](procedures/README.md).

PACE hardware, quotas, partitions, and policies can change. Check the [official PACE site](https://pace.gatech.edu/) and linked Georgia Tech documentation when planning a job.
