# 100 - Access and Setup

Start here if you are new to PACE ICE. This module covers the setup work that needs to happen before you can run a job: connecting to the Georgia Tech VPN, logging in, understanding the PACE environment, and finding the right access and orientation resources.

## In this module

1. [101 - How to Install and Configure GlobalProtect VPN](101%20-%20How%20to%20Install%20and%20Configure%20GlobalProtect%20VPN/101-HowtoInstallandConfigureGlobalProtectVPN_2026-07-09.md) - install GlobalProtect and connect to Georgia Tech's VPN.
2. [102 - Logging Into OnDemand and SSH](102%20-%20Logging%20Into%20OnDemand%20and%20SSH/102-LoggingIntoOnDemandandSSH_2026-07-18.md) - access ICE through a terminal or the Open OnDemand website.
3. [103 - Understanding the PACE Ecosystem](103%20-%20Understanding%20the%20PACE%20Ecosystem/103%20-%20Understanding%20the%20PACE%20Ecosystem.md) - learn what PACE, ICE, login nodes, compute nodes, and Slurm are.
4. [104 - Requesting ICE Access](104%20-%20Requesting%20ICE%20Access/104%20-%20Requesting%20ICE%20Access.md) - understand who requests access and what information is needed.
5. [105 - Orientation Resources](105%20-%20Orientation%20Resources/105%20-%20Orientation%20Resources.md) - find official PACE documentation, workshops, videos, and live help.

## By the end of this module

Once access has been approved, you should be able to connect to the VPN, log into ICE through SSH or OnDemand, understand why jobs are submitted through Slurm, and know where to go when you need help.
