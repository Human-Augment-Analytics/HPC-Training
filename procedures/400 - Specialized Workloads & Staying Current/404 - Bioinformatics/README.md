# 404 - Bioinformatics (Planned)

**Status:** Not completed in Summer 2026. This is a planning placeholder, not an operational procedure.

## Purpose and proposed scope

Create a domain-specific ICE workflow for a representative HAAG bioinformatics task. The procedure should address software environments, data sensitivity, storage/transfer, resource sizing, Slurm execution, and reproducible outputs without assuming that one pipeline represents the entire field.

## Required roles and prerequisites

- Procedure owner, PACE reviewer, bioinformatics subject-matter expert, and data-governance reviewer where needed.
- Approved sample data, a versioned toolchain, current storage/retention rules, and a safe example workload.

## Planned workflow and success criteria

Document input preparation, environment setup, sizing, submission, monitoring, output validation, provenance, cleanup, and escalation. Success means a new learner can run the approved sample with dummy or permitted data and explain how to adapt the resource request responsibly.

## Lessons and next steps

Resolve the exact learner task and data constraints before writing commands. Validate with domain experts and independent learners before release.
