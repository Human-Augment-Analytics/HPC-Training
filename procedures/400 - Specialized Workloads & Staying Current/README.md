# 400 — Specialized Workloads & Staying Current

Module 400 introduces advanced computing workflows and tools that researchers can use. This module focuses on applying high-performance computing (HPC) resources to specialized research tasks, including large language models (LLMs), distributed machine learning, and bioinformatics.

This module emphasizes the importance of staying informed about updates to PACE, maintaining computational environments, and following best practices for efficient and reproducible research.

## In this module

1. **[401 — Running LLMs with Ollama](301%20-%20Storage%20on%20ICE/301%20-%20Storage%20on%20ICE.md)** — what Ollama is, how to request appropriate GPU resources, and how to manage pretrained language models.
2. **[402 — Staying Current](302%20-%20Auditing%20Your%20Storage%20Usage/302%20-%20Auditing%20Your%20Storage%20Usage.md)** — focuses on tips on maintaing reliable computing environments and staying informed about updates to PACE and ICE.
3. **[403 — Distributed Training](303%20-%20Validating%20Your%20Job%20Before%20Submission/303%20-%20Validating%20Your%20Job%20Before%20Submission.md)** — 
fundamentals of distributed training.
4. **[404 — Bioinformatics](304%20-%20Checking%20System%20Status/304%20-%20Checking%20System%20Status.md)** — explores how HPC resources can cupport biology and bioinformatics research.
