# 400 — Specialized Workloads & Staying Current

Module 400 introduces advanced computing workflows and tools that researchers can use. This module focuses on applying high-performance computing (HPC) resources to specialized research tasks, including large language models (LLMs), distributed machine learning, and bioinformatics.

This module emphasizes the importance of staying informed about updates to PACE, maintaining computational environments, and following best practices for efficient and reproducible research.

## In this module

1. **[401 — Running LLMs with Ollama](401%20-%20Running%20LLMs%20with%20Ollama/README.md)** — Learn what Ollama is, how to request appropriate GPU resources, and how to manage pretrained language models.

2. **[402 — Staying Current](402%20-%20Staying%20Current/README.md)** — Learn how to maintain reliable computing environments and stay informed about updates to PACE and ICE.

3. **[403 — Distributed Training](403%20-%20Distributed%20Training/README.md)** — Explore the fundamentals of distributed training and how to use multiple GPUs for machine learning workloads.

4. **[404 — Bioinformatics](404%20-%20Bioinformatics/README.md)** — Explore how HPC resources can support computational biology and bioinformatics research.
