# HPC Training Curriculum

Follow the modules in order if you are new to ICE, or open the module that matches your task.

| Module | Topics |
|---|---|
| [100 - Access and Setup](100%20-%20Access%20and%20Setup/README.md) | VPN, ICE login, the PACE ecosystem, access requests, and orientation resources. |
| [200 - Running Your First Job](200%20-%20Running%20Your%20First%20Job/README.md) | Resource sizing, GPU choice, VRAM estimates, Slurm submission, and output checks. |
| [300 - Storage, Troubleshooting & Support](300%20-%20Storage%2C%20Troubleshooting%20%26%20Support/README.md) | Storage usage, job validation, system status, and support. |

Start with [101 - GlobalProtect VPN](100%20-%20Access%20and%20Setup/101%20-%20How%20to%20Install%20and%20Configure%20GlobalProtect%20VPN/101-HowtoInstallandConfigureGlobalProtectVPN_2026-07-09.md) if you need to connect from off campus. If you can already log into ICE, go to [201 - The Four Numbers Before You Submit](200%20-%20Running%20Your%20First%20Job/201%20-%20The%20Four%20Numbers%20Before%20You%20Submit/201%20-%20The%20Four%20Numbers%20Before%20You%20Submit.md).

For current cluster details and policies, use the [official PACE documentation](https://pace.gatech.edu/).
